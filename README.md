# Sakshi Sonavane — Data & AI Portfolio

A responsive, static portfolio website built with HTML, CSS, and vanilla JavaScript. It includes project showcases, internship timeline, skills, education, contact links, project filters, a mobile navigation menu, and a light/dark theme toggle.

## Run locally

No build step is required. Open `index.html` in a browser, or use a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` from the portfolio folder.

## Deploy

Upload the contents of this folder to a static hosting provider such as GitHub Pages, Netlify, or Vercel. Keep `assets/Sakshi_Sonavane_Resume.pdf` at the same relative path so the résumé link works.
